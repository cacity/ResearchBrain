# Support

Use GitHub Discussions for setup questions and research workflows after the repository is published. Use an
issue only for a reproducible defect or a scoped feature request, following the provided templates.

Before asking for help, include the application version, Windows version, failing stage, sanitized error code,
and whether the same problem occurs with PyMuPDF fallback. Never publish API keys, private PDFs, Zotero
databases, browser cookies, or absolute personal paths.

Security issues belong in the private channel described in [SECURITY.md](SECURITY.md).
