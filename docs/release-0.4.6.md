# ResearchBrain 0.4.6 测试版说明

发布日期：2026-09-06

## 本版重点

- 修正“全网调研”首轮检索为空后被强制直接综合、最终只显示一句无证据提示的问题。
- 在线检索最多执行两轮。首轮按计划使用来源适配检索；首轮无有效证据时，第二轮移除
  `ConvLSTM`、`UNet`、`deep learning`、`prediction` 等过窄限定，保留核心研究对象并同时检索
  Crossref、OpenAlex、arXiv 和 PubMed。
- 覆盖评估在零证据且允许联网时不能提前选择综合。
- 每个在线来源增加独立的 18 秒上限，单个来源异常不会拖到整个 45 秒工具调用才暴露。
- 所有来源仍未获得证据时，界面显示已执行检索式、来源异常和后续处理建议。

## 验证范围

- 回归测试覆盖“首轮来源适配检索为空、第二轮跨来源检索成功并继续生成引用答案”。
- 回归测试覆盖来源级超时隔离和在线空结果诊断报告。
- 使用真实在线请求验证 `ionospheric TEC earthquake`：四个来源均成功，合并得到 12 条记录。
- Python 全量测试、Ruff、TypeScript/Vite、Rust 和安装包构建。
