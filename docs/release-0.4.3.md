# ResearchBrain 0.4.3 测试版说明

发布日期：2026-09-05

## 本版重点

- 修正联网检索已找到证据、模型也已生成报告，但因行内引用格式不符合协议而显示
  `Model answer did not cite supplied evidence in its text` 的问题。
- 自动把 `【W5】`、`(W5)`、`[w5]` 等常见写法统一为 `[W5]`。
- 当回答声明了合法证据编号但遗漏行内标记时，执行一次仅限引用绑定的修复，不允许引入新证据、
  DOI、作者、方法或结果。
- 若模型修复仍失败或模型额度不可用，返回带引用的已筛选证据目录和明确限制，不再把整次调研
  标记为失败。
- 引用了证据账本中不存在的编号仍会硬性拒绝，避免伪造引用被自动掩盖。

## 验证范围

- 引用遗漏自动修复。
- 全角括号、圆括号和小写证据编号归一化。
- 修复模型不可用时的确定性降级输出。
- 非法证据编号继续被拒绝。
- Python 全量测试、Ruff、TypeScript、Vite 和 Prettier。
