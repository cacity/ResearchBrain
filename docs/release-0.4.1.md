# ResearchBrain 0.4.1 测试版说明

发布日期：2026-09-05

## 本版重点

- 修正明确调研问题被模型误判为“必须澄清”并在等待后失败的问题。
- 有具体领域、对象或方法的宽泛问题直接进入规划；未指定的应用分支和报告格式作为合理默认
  范围处理，不再阻断检索。
- 未采纳的歧义文本不会写入后续假设，避免错误跨域词污染检索与回答。
- 真正缺少主题的问题会显示专用澄清输入区，可在同一运行中提交答案并继续。
- 澄清等待超时后返回可见的中文问题，不再显示英文内部错误。
