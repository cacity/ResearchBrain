# ResearchBrain 0.4.4 测试版说明

发布日期：2026-09-06

## 本版重点

- 修正完成调研后只显示几句话或残缺编号的问题。
- 实际运行显示，模型初稿约 3700 个中文字符、包含 6 个章节；旧 Claim Extractor 将 Markdown
  标题、表格、列表和正文压成事实句，Reviewer 因此产生 32 个阻断项，修订后仍有 26 个，最终
  删除逻辑将报告缩短为 191 个字符。
- 主张提取现按 Markdown 段落和表格行处理，并保留章节语义：文献事实需要引用，研究建议、
  可检验假设和明确的证据缺口不会被误判为漏引事实。
- 初稿只有部分事实带引用时，会在 Reviewer 前执行一次引用绑定修复。
- 最终审查按主张粒度删除不支持内容，同时保留标题、表格和列表结构。
- 若生成稿或审查后结果过短、章节不足或留下残缺列表，自动重建为完整的受限调研报告，包含
  文献证据表、子问题覆盖矩阵、证据缺口、建议检索式、后续研究步骤和限制。
- “研究过程”正文由 9px 提升到 12px，章节标题提升到 13px，并增加行距和长列表滚动高度。

## 验证范围

- Markdown 标题、表头和分隔行不再被识别为事实主张。
- 表格行引用能够绑定到同一行文献事实。
- “可开展的工作”“可检验假设”“证据边界”保持各自的认识类型。
- 已有部分引用但局部漏引的回答会在审查前修复。
- 过度删减和初始短报告都会触发结构化受限报告。
- Python 全量测试、Ruff、TypeScript、Vite、Prettier 和四组桌面 Playwright 检查通过。
