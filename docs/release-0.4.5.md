# ResearchBrain 0.4.5 测试版说明

发布日期：2026-09-06

## 本版重点

- 修正混合调研在本地检索结束时出现 `zip() argument 2 is longer than argument 1` 的问题。
- 真实失败运行中，Agent 请求了 6 次本地搜索，其中同一条长检索式完全重复 3 次；查询规格去重后为 4 条，而工具层仍返回 6 条结果，旧代码使用严格位置配对并终止整轮。
- 执行前删除参数完全相同的重复搜索，避免浪费检索时间和工具调用预算。
- 相同检索词面向不同在线来源时仍保留为独立调用，并建立一一对应的诊断规格。
- 即使未来工具层返回数量异常，也会记录诊断并处理能够对应的结果，不再把 Python 内部异常直接显示给用户。
- 延续 `0.4.4` 的调研报告完整性修复和放大的“研究过程”字号。

## 验证范围

- 使用本次真实失败中的“重复搜索调用”形态建立回归测试。
- 验证重复调用只执行一次，工具预算按实际调用数计算。
- 验证同一检索词发送到 Crossref 与 OpenAlex 时不会被错误合并。
- Python 全量测试、Ruff、TypeScript/Vite/Prettier、Playwright、Rust 和打包侧车 MCP 检查。
